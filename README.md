# flexbox-generator
CSSの `display: flex`（Flexbox）の各種プロパティをブラウザ上で直感的に操作し、レイアウトの挙動をリアルタイムで確認しながらCSSコードを生成できるWebツールです。

## 主な機能

* **コンテナプロパティのリアルタイム調整**
  * `flex-direction`（並ぶ向き）
  * `justify-content`（主軸の配置）
  * `align-items`（交差軸の配置）
  * `flex-wrap`（折り返し）
  * `gap`（アイテム間のすき間：0〜48px）
* **アイテム数の変更**
  * 1〜12個の間で自由にアイテム数を増減可能
* **個別アイテムのスタイル設定**
  * 任意のアイテムを選択し、`align-self` および `flex-grow`（0〜5）を個別に指定可能（設定したアイテムのみ `:nth-child()` としてCSSに出力されます）
* **CSSコードの自動生成＆ワンクリックコピー**
  * プレビューの変更に合わせてCSSコードを即時生成し、ボタンひとつでクリップボードにコピー可能
* **レスポンシブ＆ダークモード対応**
  * スマートフォンでも操作しやすいUI設計と、OSのカラースキーム（ライト／ダークモード）への自動対応

## 使い方

1. `index.html`（または `フレックスボックス ジェネレーター.html`）をブラウザで開きます（ビルド環境やサーバーは不要です）。
2. 画面上のボタンやスライダーを操作して、Flexboxの配置やアイテム数を調整します。
3. 特定のアイテムだけ配置や伸び率を変えたい場合は、「個別アイテムの設定」から番号をタップして設定します。
4. 画面下部に生成されたCSSを確認し、「**CSSをコピー**」ボタンを押してプロジェクトに貼り付けます。

## 技術スタック

* HTML5
* CSS3（CSS Variables, Flexbox, Media Queries）
* Vanilla JavaScript（依存ライブラリなしの単一HTMLファイル構成）
